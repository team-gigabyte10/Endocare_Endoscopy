Design a modern, professional desktop software home page for a medical endoscopy management application named **“Endocare”**.

The software will be developed using **Python** and is intended for use on Windows desktop computers in hospitals, diagnostic centers, and endoscopy clinics.

### Overall UI Style

* Professional medical software aesthetic
* Clean, modern, minimal interface
* Desktop-first layout optimized for 1366×768 and 1920×1080 screens
* Light background with subtle medical-themed visual elements
* Use a professional blue/teal-based medical color palette
* Rounded cards and buttons with subtle shadows
* Clear typography and excellent readability
* Avoid excessive decoration
* Make the interface look like a real commercial healthcare desktop application

### Header

Create a fixed top header containing:

**Left side:**

* Endocare logo/icon
* Application name: **Endocare**
* Small subtitle: **Endoscopy Management System**

**Right side:**

* Current date and time
* Logged-in user name
* User/profile icon
* Settings icon
* Minimize, maximize, and close window controls

### Main Navigation / Home Page

Create a prominent home dashboard containing the following main functions as large professional buttons/cards:

1. **New Patient**

   * Medical/user icon
   * Subtitle: “Register a new patient”
   * Opens the patient registration workflow

2. **Patients Archive**

   * Archive/folder icon
   * Subtitle: “View and manage patient records”

3. **Doctors**

   * Doctor/physician icon
   * Subtitle: “Manage doctors”

4. **Referrers**

   * Referral/medical icon
   * Subtitle: “Manage referring physicians”

5. **Template**

   * Document/template icon
   * Subtitle: “Manage report templates”

Arrange these buttons in a clean dashboard grid with consistent sizing.

### Capture Card Library Dropdown

Add a clearly visible **“Capture Card Library”** dropdown/menu in the home page.

The dropdown should include:

* Capture Card Library
* Manage Capture Cards
* Add New Capture Card
* Edit Capture Card
* Delete Capture Card

Use a small camera/card icon beside the dropdown label.

The Capture Card Library represents reusable endoscopy image/report capture cards and should look like an important clinical workflow feature.

### Dashboard Layout

Use a spacious dashboard layout:

Top:
**Welcome to Endocare**
“Endoscopy Management System”

Below:
Large functional cards for:

* New Patient
* Patients Archive
* Doctors
* Referrers
* Template

Place **Capture Card Library** prominently near the main dashboard controls as a dropdown.

### Visual Requirements

* Use consistent icons throughout the interface.
* Buttons should have clear hover and active states.
* Use subtle borders and shadows.
* Maintain strong visual hierarchy.
* Ensure all text is readable at normal desktop scaling.
* Use professional medical terminology.
* Do not overcrowd the screen.
* Avoid mobile-app styling; this must look like a **Windows desktop healthcare application**.
* Include realistic sample data only where necessary for visual presentation.

### Final Output

Generate a polished, high-fidelity **Endocare desktop application Home Page UI mockup**, suitable as a reference for implementing the interface in **Python using PySide6/PyQt**.
